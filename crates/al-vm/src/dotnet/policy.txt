# What is refused before a DotNet request reaches .NET (ADR-014 section 8).
#
# One rule per line: `<kind> <subject> | <rule shown in the refusal>`. Lines starting with `#`
# and blank lines are ignored. Names are compared ignoring ASCII case.
#
#   deny-assembly <prefix>          assembly whose simple name starts with <prefix>
#   allow-type <Type>               this exact CLR type is exempt from deny-type (never a prefix)
#   deny-type <name>                this CLR type; a name ending in `.` is a namespace prefix
#   deny-type-off-windows <name>    as deny-type, but lifted when the .NET host runs on Windows
#   deny-member <Type.Member>       this member of this CLR type
#   deny-new-without-args <Type>    construction with no arguments
#   server-prefix <prefix>          assemblies and types that are server classes
#   pure <Type>                     a server class shown to work with no session
#
# A server class (a `server-prefix` match) is sent to .NET only if it is `pure`. Everything
# else is the runtime's own business, through the registry (item 1).

# Item 1: server classes. A type goes on the pure list only when a corpus test or a probe
# shows it works with no session. Base64UrlHelper is the one the spike ran (ADR-014 section 12).
server-prefix Microsoft.Dynamics.Nav. | server class
pure Microsoft.Dynamics.Nav.Types.Base64UrlHelper | spike: runs with no session (ADR-014 section 12)

deny-assembly Azure. | the Azure SDK needs the network

deny-assembly Microsoft.Identity.Client | OAuth clients need the network

deny-assembly Microsoft.Dynamics.Nav.Smtp | SMTP needs the network

# ADR-044: the eight members of O365 Brand Color.MakePicture are served by the registry (dotnet/drawing.rs), which is
# consulted before this policy. ADR-027 row 14 (amended 2026-10-29): on Windows every other System.Drawing type and
# member goes to .NET (GDI+, the same bytes as BC); on any other OS it stays refused here.
deny-type-off-windows System.Drawing. | needs the Windows drawing stack (AL Runner refuses it for the same reason)
deny-member System.Threading.Thread.Sleep | wall-clock wait

# Item 5: clock and randomness that bypass the host. The static members DateTime.Now, UtcNow, Today and
# DateTimeOffset.Now, UtcNow are answered from the host clock before this policy is asked (ADR-024); the
# rules below refuse every other route to them, and the rest.
deny-member System.DateTime.Now | clock that bypasses the host
deny-member System.DateTime.UtcNow | clock that bypasses the host
deny-member System.DateTime.Today | clock that bypasses the host
deny-member System.DateTimeOffset.Now | clock that bypasses the host
deny-member System.DateTimeOffset.UtcNow | clock that bypasses the host
deny-member System.Guid.NewGuid | randomness that bypasses the host
deny-new-without-args System.Random | an unseeded Random bypasses the host
deny-member System.Diagnostics.Stopwatch.GetTimestamp | clock that bypasses the host
deny-member System.Diagnostics.Stopwatch.StartNew | clock that bypasses the host
deny-member System.Diagnostics.Stopwatch.Start | clock that bypasses the host

## Linux artifacts checked on Windows (linux-artifacts, 2026-10-18)
The corpus CI runs BC in a Linux container. Official Windows BC containers (corpus repo runs 39125184978 for BC 27.5 and 39125190236 for BC 29.0, grep `WCRESULT`) differ from it in these places. The Linux value is not BC behavior; the runtime refuses these forms.
- `File.IsPathTemporary`: Windows Yes for the temporary path, files and subfolders in it, relative paths, empty and blank text. Windows No for `C:\`, `D:\`, `Z:/`, UNC paths and `/`. Linux said Yes for all of them. Refused here: every absolute, drive-letter and UNC path, `/etc/passwd`, and `\TEMP\` paths with `..`. Probe wanted: `/etc/passwd` and `TemporaryPath() + '../x.tmp'` on Windows.
- `File.Download` and `File.DownloadFromStream` return value: Windows returns Yes (the pre-set value is kept) and leaves `ToFile` untouched; Linux BC 28+ returned No. Both stay refused (no client). Probe line: Windows value Yes, `ToFile` unchanged.

- `GetDatabaseTableTriggerSetup` inbound flag values depend on the environment. They are not an oracle; the runtime encodes no Linux-only value.

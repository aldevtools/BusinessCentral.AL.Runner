Speed only, no answer changes: a fresh record of a table whose initial values are all plain values (a table with a Blob, RecordId or other object field keeps the per-record copy) shares the cached values; every write (field assign, Validate, RecordRef/FieldRef, temp or not) takes &mut through the one DerefMut that copies first, and Init or Clear put a new buffer in place, so a shared buffer reads the same values a copy would.
